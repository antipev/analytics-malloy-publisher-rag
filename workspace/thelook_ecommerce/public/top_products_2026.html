How this was calculated (for the data folks)

Built with a Malloy query against the ecommerce_explore model. It filters order items to 2026, groups by product name, and sums revenue, keeping the top five.

run: ecommerce_explore -> {
  where: order_items.Created_at ~ f`2026`
  group_by: products.Name
  aggregate: order_items.Total_Revenue
  order_by: Total_Revenue desc
  limit: 5
}
