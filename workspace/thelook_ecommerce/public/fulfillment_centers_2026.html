How this was calculated (for the data folks)

Built with a Malloy query against the ecommerce_explore model. It groups order items by distribution center, filters to 2026, and sums revenue and gross margin.

run: ecommerce_explore -> {
  where: order_items.Created_at ~ f`2026`
  group_by: distribution_centers.Name
  aggregate:
    order_items.Total_Revenue
    Total_Gross_Margin
  order_by: Total_Revenue desc
}
